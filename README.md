# P · Palais · Private RESPO

Der Ordner **P/** ist ein privater Palais innerhalb des iki1uc-Systems.
Er ist vollständig unabhängig von:

- ORT
- WELT
- NC²
- TMP
- ALL
- VECTOR
- HDF
- KI
- UNI

P ist ein **lokaler Raum**, der ausschließlich interne Dateien lädt
und keine externen Abhängigkeiten besitzt.

## Funktionen

### 1. Palais-Raum
`P.room` definiert den Kernraum des Palais.

### 2. TMP-Scan
Alle `.tmp` Dateien werden eingelesen und als Panels dargestellt.

### 3. ID-System
`id.html` zeigt die Palais-ID, Status und Struktur.

### 4. Unabhängigkeit
Der Palais ist vollständig autark und benötigt keine externen RESPOs.
